<!-- introdution -->

Designly is a modern, web-based graphic design application developed to simplify the process of creating visual content. The platform is inspired by popular design tools such as Canva and is designed to provide an intuitive, drag-and-drop interface for users to create professional-quality designs with ease.The application allows users to sign in securely using Google authentication and work on a dynamic canvas where they can add, edit, and arrange shapes, text, images, and templates. Designly supports essential design features such as customizable colors, fonts, layouts, and templates, making it suitable for both beginners and intermediate users.To enhance productivity.

<!-- Problem statement -->

In the current digital era, creating visual designs has become an essential requirement for students, professionals, and content creators. However, many available graphic design applications are either complex to use, require advanced design skills, or depend on expensive subscription models. This creates a barrier for beginners and students who need a simple, affordable, and easy-to-use platform for designing posters, presentations, social media graphics, and other visual content.

<!-- algorithems used -->

1. Collision Detection Algorithm

Why used:
Prevents elements from overlapping incorrectly or helps show snap-to-guide lines.

How it works:
Checks whether the bounding boxes of two objects intersect.

2. Rendering Algorithm

Why used:
Displays all elements (text, images, shapes) smoothly on the screen.

How it works:
Redraws the canvas whenever an object is moved, resized, or edited.

3. Undo / Redo Algorithm (Stack)

Why used:
Allows users to undo or redo actions.

How it works:
Uses two stacks to store previous and undone actions.
